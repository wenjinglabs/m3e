<p> <code>m3e-icon</code> 组件渲染 <a href="https://fonts.google.com/icons" target="_blank" rel="noopener noreferrer">Material Symbols</a> 图标。默认使用可变字体渲染,站点已自托管全部三套变体字体。 </p>

```js
import "m3e/icon";
```

## 用法

### 基础用法

<p>使用 <code>name</code> 特性指定图标名称。</p>

<Demo name="zh/components/icon/1" />

<p>在<a href="/icons/">图标总览</a>页可以浏览并搜索全部 4000+ 图标,点击即复制名称。</p>

### 尺寸与颜色

<p>图标的尺寸与颜色跟随文字环境:通过 <code>--m3e-icon-size</code> 调整大小,<code>color</code> 控制颜色。</p>

<Demo name="zh/components/icon/2" />

### 变体

<p>使用 <code>variant</code> 特性切换三套外观,使用 <code>filled</code> 特性切换填充态。</p>

<Demo name="zh/components/icon/3" />

### 粗细与光学尺寸

<p><code>weight</code> 特性控制笔画粗细(100-700),<code>optical-size</code> 控制光学尺寸(20-48),两者映射到可变字体轴。</p>

<Demo name="zh/components/icon/4" />

### SVG 图标

<p>除了可变字体,还可以使用 <code>m3e-icons</code> 包提供的 SVG 图标。SVG 按变体家族组织,导入即自动注册到 <code>m3e-icon</code>:</p>

```js
import "m3e-icons/outlined/search";
import "m3e-icons/outlined/home";
```

<p>也可以一次注册整个变体家族(<code>import "m3e-icons/outlined"</code>)。未注册的图标会回退到 Material Symbols 可变字体渲染。</p>
