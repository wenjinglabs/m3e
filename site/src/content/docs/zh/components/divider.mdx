<p> <code>m3e-divider</code> 组件使用一条细线,在布局、列表或容器内以不显眼的方式分隔内容。 </p>

```js
import "m3e/divider";
```

## 用法

### 列表

<p>下面的示例演示如何使用 <code>m3e-divider</code> 在 <code>m3e-list</code> 的项目之间提供分隔符。有关列表的更多信息,请参阅 <a href="/components/list/">List 列表</a>。</p>

<Demo name="zh/components/divider/0" />

### 独立使用

<p><code>m3e-divider</code> 可以单独使用,创建一条水平(或垂直)线。</p>

### 内缩

<p> 使用 <code>inset</code> 特性控制分隔线是否内缩。你也可以使用 <code>inset-start</code> 与 <code>inset-end</code> 分别控制起始或结束内缩。 </p>

<Demo name="zh/components/divider/1" />

### 方向

<p>使用 <code>vertical</code> 特性控制分隔线是否垂直朝向。</p>

```html
<m3e-divider vertical></m3e-divider>
<m3e-divider vertical inset></m3e-divider>
<m3e-divider vertical inset-start></m3e-divider>
<m3e-divider vertical inset-end></m3e-divider>
```

### 波浪

<p>使用 <code>variant="wavy"</code> 渲染波浪形分隔线，适合作为页面区块之间的柔和过渡。使用 <code>size</code> 特性选择预设尺寸（<code>small</code>、<code>medium</code> 或 <code>large</code>，默认 <code>medium</code>），无需自己填写数值。</p>

<Demo name="zh/components/divider/2" />

<p>如需进一步微调，也可以通过 CSS 自定义属性覆盖预设：<code>--m3e-divider-wavy-amplitude</code>（波幅）、<code>--m3e-divider-wavy-height</code>（波浪整体高度）与 <code>--m3e-divider-thickness</code>（线宽）。</p>

### 特性

<p><code>variant</code>：分隔线外观，<code>solid</code>（默认）或 <code>wavy</code>。</p>
<p><code>size</code>：波浪的预设尺寸，<code>small</code>、<code>medium</code>（默认）或 <code>large</code>。</p>
<p><code>vertical</code>：是否垂直朝向。</p>
<p><code>inset</code>：两侧同时内缩。</p>
<p><code>inset-start</code>：起始侧内缩。</p>
<p><code>inset-end</code>：结束侧内缩。</p>
