<p> The <code>m3e-divider</code> component visually separates content within layouts, lists, or containers using a thin, unobtrusive line. </p>

```js
import "m3e/divider";
```

## Usage

<p>This section outlines usage examples and configuration guidance for the components in this module.</p>

### Lists

<p> The following example illustrates use of the <code>m3e-divider</code> to provide separators between items in a <code>m3e-list</code>. For more information on lists, see <a href="/en/components/list/">List</a>. </p>

<Demo name="en/components/divider/0" />

### Standalone

<p>A <code>m3e-divider</code> can be used on its own to create a horizontal (or vertical) line.</p>

### Inset

<p> Use the <code>inset</code> attribute to control whether the divider is inset. Alternatively, use <code>inset-start</code> and <code>inset-end</code> to control the start or end inset. </p>

<Demo name="en/components/divider/1" />

### Orientation

<p>Use the <code>vertical</code> attribute to control whether a divider is oriented vertically.</p>

```html
<m3e-divider vertical></m3e-divider>
<m3e-divider vertical inset></m3e-divider>
<m3e-divider vertical inset-start></m3e-divider>
<m3e-divider vertical inset-end></m3e-divider>
```

### Wavy

<p>Use the <code>variant="wavy"</code> attribute to render a wavy divider, useful as a soft transition between page sections. Use the <code>size</code> attribute to pick a preset size (<code>small</code>, <code>medium</code> or <code>large</code>, default <code>medium</code>) instead of supplying raw values.</p>

<Demo name="en/components/divider/2" />

<p>For finer control, these presets can be overridden with CSS custom properties: <code>--m3e-divider-wavy-amplitude</code> (amplitude), <code>--m3e-divider-wavy-height</code> (overall height) and <code>--m3e-divider-thickness</code> (line thickness).</p>

### Attributes

<p><code>variant</code>: the appearance of the divider, <code>solid</code> (default) or <code>wavy</code>.</p>
<p><code>size</code>: the preset size of the wavy divider, <code>small</code>, <code>medium</code> (default) or <code>large</code>.</p>
<p><code>vertical</code>: whether the divider is oriented vertically.</p>
<p><code>inset</code>: whether the divider is inset on both sides.</p>
<p><code>inset-start</code>: whether the divider is inset on the leading side.</p>
<p><code>inset-end</code>: whether the divider is inset on the trailing side.</p>
