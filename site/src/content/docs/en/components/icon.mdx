<p> The <code>m3e-icon</code> component renders <a href="https://fonts.google.com/icons" target="_blank" rel="noopener noreferrer">Material Symbols</a> icons. It uses the variable font by default; all three variant fonts are self-hosted on this site. </p>

```js
import "m3e/icon";
```

## Usage

### Basic usage

<p>Use the <code>name</code> attribute to pick an icon.</p>

<Demo name="en/components/icon/1" />

<p>Browse and search all 4000+ icons in the <a href="/en/icons/">icon gallery</a>, click any icon to copy its name.</p>

### Size and color

<p>Icons inherit their text environment: use <code>--m3e-icon-size</code> for size and <code>color</code> for color.</p>

<Demo name="en/components/icon/2" />

### Variants

<p>Use the <code>variant</code> attribute to switch between the three appearances, and <code>filled</code> for the filled state.</p>

<Demo name="en/components/icon/3" />

### Weight and optical size

<p>The <code>weight</code> attribute (100-700) controls stroke thickness and <code>optical-size</code> (20-48) the optical size, both mapped to variable-font axes.</p>

<Demo name="en/components/icon/4" />

### SVG icons

<p>As an alternative to the variable font, the <code>m3e-icons</code> package provides SVG icons. SVGs are organized by variant family and register automatically into <code>m3e-icon</code> on import:</p>

```js
import "m3e-icons/outlined/search";
import "m3e-icons/outlined/home";
```

<p>You can also register an entire variant family (<code>import "m3e-icons/outlined"</code>). Unregistered icons fall back to the Material Symbols variable font.</p>
